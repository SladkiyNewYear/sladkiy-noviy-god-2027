# Сладкий Новый год 2027

Сайт-каталог заявок на сладкие новогодние подарки для Симферополя и Симферопольского района.

Это **не интернет-магазин**: клиент выбирает подарки и количество, отправляет заявку, после чего продавец связывается с клиентом для согласования наличия, доставки, окончательной стоимости и оплаты.

## Запуск локально

```bash
npm install
npm start
```

## Переменные окружения

```text
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_ADMIN_CHAT_ID=5233793704
PORT=3000
```

Telegram-токен не хранится в GitHub и задаётся на сервере через Environment Variables.
