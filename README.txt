СЛАДКИЙ НОВЫЙ ГОД — v17
Сайт-каталог заявок к Новому 2027 году, не интернет-магазин.

Изменения v17:
- Везде на сайте теперь Новый год 2027.
- В заявке телефон имеет фиксированный российский формат +7 (___) ___-__-__ и маску ввода.
- Email добавлен как необязательное поле.
- Клиент выбирает предпочтительный канал связи: Telegram или MAX.
- Заявка отправляет выбранный контакт и email (если указан) администратору в Telegram.
- Шапка/hero получили дополнительные новогодние анимации: перелив шапки, мерцание, снежный дрейф, плавное движение заголовка и hover-анимации.
- Нет оплаты на сайте: только заявка и последующее согласование.

ФОТО КОНФЕТ:
В проекте оставлены только те прямые изображения отдельных сладостей, для которых удалось получить надежный URL. Не подставляются случайные упаковки вместо конфеты. Для полного набора фотографий каждой из всех позиций нужны доступные прямые файлы/URL отдельных конфет; поисковые страницы сами по себе не являются изображением и не встраиваются как фото.

TELEGRAM
1. Node.js 18+
2. Создать бота через @BotFather.
3. Заполнить .env:
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_ADMIN_CHAT_ID=...
   PORT=3000
4. npm install
5. npm start

Важно: токен Telegram хранится только на сервере.
